# AI Autopilot for WordPress

**Your content autopilot.** Every day, AI Autopilot picks a topic, writes a full SEO article (outline → text → AI proofread pass), adds relevant images, inserts internal links to your products and articles, fills SEO fields (Yoast, Rank Math, SEOPress, AIOSEO) — and publishes it on your schedule. Any niche.

- 📝 **Free version** — unlimited daily articles as drafts + free stock photos
- ⚡ **Pro** — automatic live publishing, AI images, 200+ models via OpenRouter (one key), GSC/SERP topics, product content from photos, social sharing webhooks
- 🌐 Bilingual UI (English / Slovak)

## Install

1. Download the latest release zip (`ai-autopilot-X.X.X.zip`), or install from [WordPress.org](https://wordpress.org/plugins/ai-autopilot/)
2. Upload and activate in WordPress
3. Open **AI Autopilot** in the admin sidebar → paste your API key (Anthropic Claude, OpenAI, or Google AI) → add your niche keywords → done
