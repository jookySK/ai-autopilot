# Jookas AI Autopilot for WordPress

**Your content autopilot.** Every day, Jookas AI Autopilot picks a topic, writes a full SEO article (outline → text → AI proofread pass), adds relevant images, inserts internal links to your products and articles, fills SEO fields (Yoast, Rank Math, SEOPress, AIOSEO) — and publishes it on your schedule. Any niche.

- 📝 **Free version** — unlimited articles (fair use), live publishing on schedule, free stock photos
- ⚡ **Pro** — AI images, GSC/SERP topics & suggestions, content series, product content from photos, social webhooks with auto promotion
- 🌐 Bilingual UI (English / Slovak)

## Install

1. Download the latest release zip (`jookas-ai-autopilot-free-X.X.X.zip`), or install from [WordPress.org](https://wordpress.org/plugins/jookas-ai-autopilot/)
2. Upload and activate in WordPress
3. Open **Jookas AI Autopilot** in the admin sidebar → paste your API key (Anthropic Claude, OpenAI, Google Gemini, or OpenRouter) → add your niche keywords → done
